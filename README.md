> **"Elite Capture Matters: Insights from Interventions in Seed Systems with Women SHGs in India"**

## Requirements

- **Stata 16+**
- Packages (install once):
  ```stata
  ssc install outreg2
  net install heckprobitfixedrho
  ```

---

## How to Replicate

1. Clone or download this repository.
2. Open Stata and `cd` to the repo root.
3. Run:
   ```stata
   do code/analysis_main.do
   ```
4. Outputs appear in `output/tables/` and `output/figures/`.

**Do not edit files under `data/raw/`** — treat them as read-only originals.

## Data

The dataset `data/raw/elite_capture_baseline_replication.dta` is the baseline survey of women Self-Help Group (SHG) members in India. Key variables:

| Variable | Description |
|----------|-------------|
| `seed_producer_2016` | Binary: became a seed producer by 2016 (outcome) |
| `cbsp` | Binary: selected as community-based seed producer (selection) |
| `membership_new` | SHG membership type (elite capture indicator) |
| `age`, `age_sq` | Age and age-squared |
| `TotalFamilyMembers` | Household size |
| `land_ha` | Landholding in hectares |
| `social_category` | Social group (SC/ST/OBC/General) |
| `education` | Education level |
| `house_type` | Housing quality |
| `economic_status` | Asset-based economic status |
| `mnrega` | MNREGA participation (binary) |
| `homogenous_group` | Group homogeneity (exclusion restriction) |

See `docs/codebook.md` for full variable definitions.
